
# Paradise Nursery Shopping Application

Paradise Nursery is a dynamic React and Redux e-commerce web application designed for an online plant shop. Users can browse through a curated selection of houseplants grouped by category, add items to a dynamic shopping cart, manage item quantities, and view real-time price calculations.

## Features

- **Landing Page:** Welcoming landing hero page featuring company background details and a "Get Started" call-to-action button.
- **Product Catalog:** Interactive plant listing organized into 3 distinct categories with over 18 unique houseplants, complete with images, descriptions, and prices.
- **Dynamic Shopping Cart:** 
  - Cart counter badge on the persistent navigation bar.
  - "Add to Cart" state management that disables buttons for items already in the cart.
  - Full cart view showing unit prices, dynamic line-item total calculations, and overall order totals.
  - Interactive quantity adjustments (`+` / `-`), individual item removal, and "Continue Shopping" routing.

## Tech Stack

- **Frontend:** React.js
- **State Management:** Redux Toolkit
- **Styling:** CSS3 (Flexbox/Grid, Custom Properties)
- **Build Tool:** Vite / Create React App
